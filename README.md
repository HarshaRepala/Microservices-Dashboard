# Microservices Dashboard

A React frontend for the Order Management System built with **React**, **Vite**, **Tailwind CSS**, and **React Router**. It integrates with Spring Boot microservices for authentication, inventory management, and order management.

## Live Application

- **Login Page:** https://harsharepala.github.io/Microservices-Dashboard/#/login
- **Register Page:** https://harsharepala.github.io/Microservices-Dashboard/#/register
- **Dashboard Page:** https://harsharepala.github.io/Microservices-Dashboard/#/dashboard

## Tech Stack

- React
- Vite
- React Router
- Tailwind CSS
- Axios
- Framer Motion
- React Hot Toast
- Lucide React
